# 行程圖片

把圖片放進這個資料夾，檔名要一模一樣，App 會自動顯示在對應的那一天：

| 檔名 | 用在哪一天 | 內容 |
|---|---|---|
| `day1-jungfrau-rail-map.jpg` | DAY 1 (10/01) | 少女峰地區纜車與鐵道地圖 |
| `day2-first-adventure-map.jpg` | DAY 2 (10/02) | Grindelwald First 山頂設施位置圖 |
| `day3-oeschinensee-map.jpg` | DAY 3 (10/03) | 厄希嫩湖夏季健行地圖 |

- 格式：`.jpg`（若要用 png，記得同時改 `switzerland_italy_trip_app.html` 裡 `img.src` 的副檔名）
- 建議寬度 1200–1600 px，單張控制在 500 KB 以內，手機載入比較快
- 檔案還沒放進來時，App 會顯示一個提示框，不會壞版
